# Gokulraj V — Full Stack Developer Portfolio

A modern, responsive, and clean Developer Portfolio for **Gokulraj V**, Full Stack MERN Developer and Web & Mobile Application Developer.

## 🚀 Technologies

- **Frontend**: React.js 18, Vite, JavaScript (ES6+), TypeScript, Tailwind CSS
- **Mobile Development**: React Native, Expo, Android Application Development
- **Backend & Database**: Node.js, Express.js, REST APIs, MongoDB, Mongoose ODM
- **Icons & Motion**: Lucide React, Framer Motion
- **Tooling**: Git, GitHub, Postman, Azure DevOps

## 🌟 Key Features

- **Full-Stack & Mobile Showcase**: Highlights dual expertise in Web Applications and Cross-Platform Mobile Applications.
- **Data-Driven Architecture**: All projects, skills, services, and experiences are managed cleanly through modular data files in `src/data/`.
- **Dynamic Project Filtering**: Filter by `All`, `Web Applications`, `Mobile Apps`, `Full Stack`, and `In Development`.
- **Active Development Spotlight**: Dedicated section showcasing in-development platforms (`SoftyeOne Invoice`, `Softye PG Management`).
- **Dedicated Case Study Pages**: Comprehensive details for major systems (`/project/:id`).
- **Responsive Layout**: Pixel-perfect viewports across Mobile (320px–414px), Tablet (768px–1024px), and Desktop (1280px–1920px).
- **Theme Modes**: Seamless Dark Mode / Light Mode with local storage persistence and system preference detection.
- **Interactive Resume**: Integrated PDF download (`public/resume/Gokulraj-V-Resume.pdf`), dedicated view route (`/resume`), and modal viewer.

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
